== Name

poedit - appliquer des mappages gettext à des fichiers *.po*

== Synopsis

*poedit* [options] [fichier-po]...

== Description

*poedit* lit des lignes mappage UTF-8 (tabulations) contenant *msgid* et *msgstr*
et intègre les *msgstr* dans des catalogues *.po* GNU par langue. Préparez d'abord
les textes, puis lancez un passage unique ; le programme ne génère pas de *msgstr*
à partir du seul *msgid*.

Sans arguments _fichier-po_, il met à jour _po-dir_/_langue_.po si le fichier est
présent. Avec des chemins, seuls ceux-là. Résolution: voir `poedit --help`.

== Input format

Chaque ligne non vide est séparée sur des tabulations (tabulation horizontale, Unicode *U+0009* ou ASCII 0x09), et non sur des espaces.
Échappements de style C possibles. Deux dispositions :

1. *Avec colonne langs :* _langs_ (codes séparés par des virgules), *msgid*, puis une colonne *msgstr* par langue.
2. *Sans colonne langs :* *msgid* et *msgstr* ; langues fournies par *-l* */* *--langs* ou le chemin.

Le nombre de colonnes *msgstr* doit égaler le nombre de langues ; cf. `poedit --help`.

== Options

*-i* _chemin_, *--input*=_chemin_::
  Fichier ou répertoire, sinon *stdin*.

*-l* _langs_, *--langs*=_langs_::
  Codes de langue séparés par des virgules si la ligne n'a pas de colonne _langs_ ; le nombre de colonnes *msgstr* doit correspondre.

*-p* _dir_, *--po-dir*=_dir_::
  Base (défaut: *po*).

*-d*, *--dry-run*::
  Afficher le plan sans modifier les fichiers.

*-v*, *--verbose*::
  Plus de messages.

*-q*, *--quiet*::
  Moins de messages.

*-h*, *--help*::
  Afficher l'aide et quitter avec succès.

*--version*::
  Afficher la version et quitter avec succès.

Les opérandes suivants sont des _chemins po_ à mettre à jour.

== Exit status

*0*::
  Success.

*1*::
  Error.

== Environment

*LC_ALL*, *LC_MESSAGES*, *LANG*, *LANGUAGE*::
  sélectionnent la langue de `poedit --help` et diagnostics associés. Ils ne modifient pas le contenu des mappages ni des *.po*.
