== Name

poedit - Mappings in GNU gettext *.po*-Dateien eintragen

== Synopsis

*poedit* [Optionen] [po-Datei]...

== Description

*poedit* liest UTF-8, tabulatoregetrennte Mapping-Zeilen zu *msgid* und *msgstr*
und führt die *msgstr*-Werte in *.po*-Katalogen zusammen, nach Sprache geordnet.
Übersetzungen vorbereiten, dann in einem Rutsch einspielen; es werden keine
*msgstr* allein aus *msgid* generiert.

Standardziele heißen _po-dir_/_sprache_.po, wenn die Datei existiert. Wenn
_po-Datei_-Argumente angegeben werden, nur diese. Auflösung von Sprachangaben: siehe
`poedit --help`.

== Input format

Jede nichtleere Zeile wird an Tabulatorzeichen getrennt (horizontaler Tab, Unicode *U+0009* bzw. ASCII 0x09), nicht an Leerzeichen.
Optionale C-Escapes in den Feldern. Zwei Layouts:

1. *Mit langs-Spalte:* _langs_ (kommagetrennte Sprachcodes), *msgid* und je eine *msgstr*-Spalte pro Sprache.
2. *Ohne langs-Spalte:* *msgid* und *msgstr*-Spalten; Sprachen aus *-l* */* *--langs* oder dem Pfad.

Die Anzahl der *msgstr*-Spalten muss der Sprachanzahl entsprechen; siehe `poedit --help`.

== Options

*-i* _pfad_, *--input*=_pfad_::
  Datei oder Verzeichnis; fehlt *-i*, Standard-Eingabe.

*-l* _langs_, *--langs*=_langs_::
  Kommagetrennte Sprachcodes, wenn keine langs-Spalte in der Zeile; Anzahl der *msgstr*-Spalten muss passen.

*-p* _verz_, *--po-dir*=_verz_::
  Basis (Vorgabe: *po*).

*-d*, *--dry-run*::
  Nur Plan anzeigen, Dateien unverändert lassen.

*-v*, *--verbose*::
  Mehr Meldungen.

*-q*, *--quiet*::
  Weniger Meldungen.

*-h*, *--help*::
  Hilfetext, dann Erfolg.

*--version*::
  Version, dann Erfolg.

Weitere Operanden sind zu aktualisierende _po-Pfade_.

== Exit status

*0*::
  Success.

*1*::
  Error.

== Environment

*LC_ALL*, *LC_MESSAGES*, *LANG*, *LANGUAGE*::
  wählen die Sprache von `poedit --help` und verwandter Diagnosen. Mapping- und *.po*-Inhalte ändern sie nicht.
