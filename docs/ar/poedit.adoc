== Name

poedit - تطبيق تعيينات gettext لـ *msgid*/*msgstr* على ملفات *.po*

== Synopsis

*poedit* [خيارات] [ملف-po]...

== Description

يقرأ *poedit* بيانات تعيين UTF-8 مفصولة بعلامات جدولة ويدمج *msgstr* في كتالوجات
*.po* حسب اللغة. حضّر الترجمات أولاً ثم طبّقها دفعة واحدة؛ لا يولّد *msgstr* من *msgid* وحده.

بدون _ملف-po_ يحدّث _po-dir_/_لغة_.po عند وجود الملف. مع وسائط يحدّث تلك الملفات فقط.
راجع `poedit --help`.

== Input format

يُقسَم كل سطر غير فارغ على علامة الجدولة (أفقي، Unicode *U+0009* / ASCII 0x09) وليس على المسافات.
يُسمح بتسلسلات تهريب بأسلوب C. تخطيطان:

1. *مع عمود langs:* _langs_ (رموز مفصولة بفواصل)، ثم *msgid*، ثم عمود *msgstr* لكل لغة.
2. *بدون عمود langs:* *msgid* و*msgstr*؛ اللغات من *-l* */* *--langs* أو المسار.

يجب أن يساوي عدد أعمدة *msgstr* عدد اللغات؛ انظر `poedit --help`.

== Options

*-i* _مسار_, *--input*=_مسار_::
  ملف أو دليل؛ وإلا الإدخال القياسي.

*-l* _langs_, *--langs*=_langs_::
  رموز لغة مفصولة بفواصل عندما لا يوجد عمود _langs_؛ يجب أن يطابق عدد أعمدة *msgstr*.

*-p* _دليل_, *--po-dir*=_دليل_::
  الأساس (الافتراضي: *po*).

*-d*, *--dry-run*::
  عرض الخطة دون تعديل الملفات.

*-v*, *--verbose*::
  المزيد من الرسائل.

*-q*, *--quiet*::
  رسائل أقل.

*-h*, *--help*::
  عرض المساعدة والخروج بنجاح.

*--version*::
  عرض الإصدار والخروج بنجاح.

بقية المعاملات هي _مسارات po_ للتحديث.

== Exit status

*0*::
  Success.

*1*::
  Error.

== Environment

*LC_ALL*, *LC_MESSAGES*, *LANG*, *LANGUAGE*::
  تختار لغة `poedit --help` والتشخيصات ذات الصلة. لا تغيّر محتوى التعيينات أو ملفات *.po*.
