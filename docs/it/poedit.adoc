== Name

poedit - applicare mappature gettext a file *.po*

== Synopsis

*poedit* [opzioni] [file-po]...

== Description

*poedit* legge mappature UTF-8 (campi separati da tab) e unisce *msgstr* ai
cataloghi *.po* per lingua. Preparare le stringhe prima, quindi lanciare un
singolo aggiornamento; non vengono generate *msgstr* solo da *msgid*.

Senza _file-po_ si aggiorna _po-dir_/_lingua_.po se esiste. Con argomenti, solo
quei file. Priorità: `poedit --help`.

== Input format

Ogni riga non vuota viene separata sui caratteri di tabulazione (tab orizzontale, Unicode *U+0009* o ASCII 0x09), non sugli spazi.
Escape in stile C possibili. Due layout:

1. *Con colonna langs:* _langs_ (codici separati da virgola), *msgid* e una colonna *msgstr* per lingua.
2. *Senza colonna langs:* *msgid* e *msgstr*; lingue da *-l* */* *--langs* o dal percorso.

Il numero di colonne *msgstr* deve coincidere; vedi `poedit --help`.

== Options

*-i* _path_, *--input*=_path_::
  File o directory, altrimenti *stdin*.

*-l* _langs_, *--langs*=_langs_::
  Codici lingua separati da virgola se manca la colonna _langs_; il numero di colonne *msgstr* deve corrispondere.

*-p* _dir_, *--po-dir*=_dir_::
  Base (def.: *po*).

*-d*, *--dry-run*::
  Solo simulazione.

*-v*, *--verbose*::
  Più messaggi.

*-q*, *--quiet*::
  Meno messaggi.

*-h*, *--help*::
  Mostra l'aiuto ed esce con successo.

*--version*::
  Mostra la versione ed esce con successo.

Gli altri operandi sono _percorsi po_ da aggiornare.

== Exit status

*0*::
  Success.

*1*::
  Error.

== Environment

*LC_ALL*, *LC_MESSAGES*, *LANG*, *LANGUAGE*::
  selezionano la lingua di `poedit --help` e diagnostiche correlate. Non modificano mappature o contenuto *.po*.
