== Name

poedit - gettext の *msgid*/*msgstr* マッピングを *.po* に反映する

== Synopsis

*poedit* [オプション] [po-ファイル]...

== Description

*poedit* は UTF-8 のタブ区切りマッピングを読み、言語ごとに *.po* カタログへ
*msgstr* をマージする。先に訳文を用意し、一括で流し込む用途向け。単に *msgid* から
*msgstr* を機械補完することは想定していません。

引数の _po-ファイル_ がなければ、入力に現れる各言語向けに _po-dir_/_言語_.po
を更新（ファイルがある場合）。_po-ファイル_ を付けると指定ファイルのみ。言語の決まり方は
`poedit --help` を参照。

== Input format

空でない各行は、スペースではなくタブ文字（水平タブ、Unicode *U+0009* / ASCII 0x09）で区切られます。
フィールド内は C 風のエスケープ可。形式は二通り:

1. *langs 列あり:* _langs_（カンマ区切りの言語コード）、*msgid*、言語ごとの *msgstr* 列。
2. *langs 列なし:* *msgid* と複数 *msgstr*。言語は *-l* */* *--langs* やパスから決定。

*msgstr* 列数は言語数と一致させる必要があります。詳細は `poedit --help`。

== Options

*-i* _パス_, *--input*=_パス_::
  1 ファイルまたは 1 ディレクトリ。未指定は標準入力。

*-l* _言語リスト_, *--langs*=_言語リスト_::
  カンマ区切りの言語コード（行に langs 列がないとき）。*msgstr* 列数は一致必須。

*-p* _ディレクトリ_, *--po-dir*=_ディレクトリ_::
  基準 *.po* パス用（既定: *po*）。

*-d*, *--dry-run*::
  書き込まず表示のみ。

*-v*, *--verbose*::
  詳しめのログ。

*-q*, *--quiet*::
  ログ控えめ。

*-h*, *--help*::
  ヘルプ。終了 0。

*--version*::
  バージョン。終了 0。

残りの引数は更新対象の _po-パス_。

== Exit status

*0*::
  Success.

*1*::
  Error.

== Environment

*LC_ALL*, *LC_MESSAGES*, *LANG*, *LANGUAGE*::
  `poedit --help` など gettext UI の言語を選びます。マッピングや *.po* 本文は変えません。
