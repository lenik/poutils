== Name

poedit - 将 gettext *msgid*/*msgstr* 批量写入 *.po*

== Synopsis

*poedit* [选项] [po-文件]...

== Description

*poedit* 读取以 UTF-8 编码、制表符分隔的映射，把各语言的 *msgstr* 合并进 GNU gettext
*.po* 文件。应事先准备好翻译再一次性套入，而不是仅凭 *msgid* “生成”*msgstr*。

无 _po-文件_ 参数时，对输入中出现的每种语言更新 _po-目录_/_语言_.po（若该文件存在）。
显式给出 _po-文件_ 时只改这些；语言等解析顺序见 `poedit --help`。

== Input format

每个非空行按制表符（水平 Tab，Unicode *U+0009* / ASCII 0x09）分割，而不是按空格分割。
字段中可使用类 C 转义。两种布局：

1. *含 langs 列：* _langs_（逗号分隔的多种语言）、*msgid*、以及每种语言一列 *msgstr*。
2. *不含 langs 列：* *msgid* 加多个 *msgstr*，语言由 *-l* */* *--langs* 或路径推断。

*msgstr* 列数须与语言数一致。详见 `poedit --help`。

== Options

*-i* _路径_, *--input*=_路径_::
  一个文件或目录；省略则从标准输入读入。

*-l* _语言列表_, *--langs*=_语言列表_::
  逗号分隔的语言代码，用于行内没有 langs 列时；*msgstr* 列数须与之匹配。

*-p* _目录_, *--po-dir*=_目录_::
  默认 *.po* 根（默认: *po*）。

*-d*, *--dry-run*::
  只显示计划，不写文件。

*-v*, *--verbose*::
  更详细日志。

*-q*, *--quiet*::
  更少输出。

*-h*, *--help*::
  打印用法并以状态 0 退出。

*--version*::
  打印版本并以状态 0 退出。

其余操作数为要更新的 _po-路径_。

== Exit status

*0*::
  Success.

*1*::
  Error.

== Environment

*LC_ALL*, *LC_MESSAGES*, *LANG*, *LANGUAGE*::
  影响 `poedit --help` 等 gettext 界面语言，不改动映射行或 *.po* 正文字面内容。
