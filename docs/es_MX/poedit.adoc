== Name

poedit - aplicar asignaciones gettext *msgid*/*msgstr* a archivos *.po*

== Synopsis

*poedit* [opciones] [archivo-po]...

== Description

*poedit* lee asignaciones UTF-8 separadas por tabuladores y fusiona *msgstr*
en catálogos *.po* de GNU gettext por idioma. Prepare las traducciones primero y
luego aplíquelas de una vez; no genera *msgstr* solo a partir de *msgid*.

Sin _archivo-po_, actualiza _po-dir_/_idioma_.po cuando el archivo existe. Con
argumentos, solo esos archivos. Resolución: vea `poedit --help`.

== Input format

Cada línea no vacía se parte en tabuladores (tab horizontal, Unicode *U+0009* / ASCII 0x09), no en espacios.
Se permiten escapes estilo C. Dos diseños:

1. *Con columna langs:* _langs_ (códigos separados por comas), *msgid* y una columna *msgstr* por idioma.
2. *Sin columna langs:* *msgid* y *msgstr*; idiomas desde *-l* */* *--langs* o la ruta.

El número de columnas *msgstr* debe coincidir; vea `poedit --help`.

== Options

*-i* _ruta_, *--input*=_ruta_::
  Archivo o directorio; si se omite, entrada estándar.

*-l* _langs_, *--langs*=_langs_::
  Códigos de idioma separados por comas cuando no hay columna _langs_; el número de columnas *msgstr* debe coincidir.

*-p* _dir_, *--po-dir*=_dir_::
  Base (predeterminado: *po*).

*-d*, *--dry-run*::
  Mostrar el plan sin modificar archivos.

*-v*, *--verbose*::
  Más mensajes.

*-q*, *--quiet*::
  Menos mensajes.

*-h*, *--help*::
  Mostrar ayuda y salir con éxito.

*--version*::
  Mostrar versión y salir con éxito.

Los operandos restantes son _rutas po_ a actualizar.

== Exit status

*0*::
  Success.

*1*::
  Error.

== Environment

*LC_ALL*, *LC_MESSAGES*, *LANG*, *LANGUAGE*::
  seleccionan el idioma de `poedit --help` y diagnósticos relacionados. No cambian el contenido de asignaciones ni de *.po*.
