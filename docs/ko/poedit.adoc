== Name

poedit - gettext *msgid*/*msgstr* 매핑을 *.po* 파일에 반영

== Synopsis

*poedit* [옵션] [po-파일]...

== Description

*poedit* 는 UTF-8, 탭으로 구분된 매핑을 읽고 언어별 GNU gettext *.po* 에
*msgstr* 을 병합한다. 먼저 번역을 준비한 뒤 한 번에 적용하는 용도이며, *msgid* 만으로
*msgstr* 을 흉내 내지는 않는다.

인자 없이 실행하면 입력에 나타난 언어에 대해 _po-dir_/_언어_.po 를 갱신(파일이 있을 때).
_po-파일_ 을 주면 그 파일만. 언어 판정은 `poedit --help` 참고.

== Input format

비어 있지 않은 각 줄은 공백이 아니라 탭 문자(가로 탭, Unicode *U+0009* / ASCII 0x09)로 구분됩니다.
C 스타일 이스케이프 가능. 두 가지 형식:

1. *langs 열 있음:* _langs_(쉼표로 구분된 언어 코드), *msgid*, 언어별 *msgstr* 열.
2. *langs 열 없음:* *msgid* 와 여러 *msgstr*. 언어는 *-l* */* *--langs* 나 경로로 결정.

*msgstr* 열 수는 언어 수와 같아야 합니다. 자세한 우선순위는 `poedit --help`.

== Options

*-i* _경로_, *--input*=_경로_::
  파일 또는 디렉터리. 생략 시 표준 입력.

*-l* _언어목록_, *--langs*=_언어목록_::
  쉼표로 구분된 언어 코드(행에 langs 열이 없을 때). *msgstr* 열 수는 일치해야 함.

*-p* _디렉터리_, *--po-dir*=_디렉터리_::
  기본 *.po* 루트(기본값 *po*).

*-d*, *--dry-run*::
  쓰지 않고 계획만 표시.

*-v*, *--verbose*::
  자세한 로그.

*-q*, *--quiet*::
  로그 감소.

*-h*, *--help*::
  도움말 후 성공 종료.

*--version*::
  버전 후 성공 종료.

나머지 인수는 갱신할 _po-경로_.

== Exit status

*0*::
  Success.

*1*::
  Error.

== Environment

*LC_ALL*, *LC_MESSAGES*, *LANG*, *LANGUAGE*::
  `poedit --help` 등 gettext UI 언어를 고릅니다. 매핑이나 *.po* 본문은 바꾸지 않습니다.
